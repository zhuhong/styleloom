# 公开技能库

这里是 StyleLoom 的**只读知识层**：一条条跨项目可复用的方法（运镜、灯光、构图、节奏、提示词、流程、避坑）。

公开技能和本机累积技能的区别：

| | 公开库 `skills/` | 本机库 `data/skills/` |
| --- | --- | --- |
| 位置 | 仓库根目录，随 git 分发 | `data/`，git 忽略 |
| 是否含证据图 | **不含**（第三方素材，版权） | 含（本地学习证据） |
| 是否含反馈/置信度 | 不含 | 含，随真实反馈动态累积 |
| 读取 | 只读 | 读写 |
| 参与检索 | 默认 `candidate / 0.32`，仅作方法参考 | 按置信度参与评分，优先 |

## 目录结构

```
skills/
├── README.md               # 本文件
├── camera-<hash>/
│   ├── skill.json          # 公开字段（无 evidence/outcomes/confidence/stats）
│   └── SKILL.md            # 人读版（证据以文字描述，不放图）
└── lighting-<hash>/
    ├── skill.json
    └── SKILL.md
```

## 怎么用

运行时 `search_skills` / `read_skill` 会同时检索公开库与本机库，**同 id 时本机覆盖公开**。公开条目不会污染你的个人资产 —— 采纳它、在本机产生真实反馈后，置信度才会在本机累积。

## 怎么贡献

1. 在本机把一条优质技能 `export_skills --dryRun` 预览（剥离证据图/反馈/置信度）。
2. `export_skills` 正式导出到 `skills/<id>/`。
3. 检查 `SKILL.md`：**不要出现本机绝对路径、小红书笔记 id、或能识别参考片作者的信息**。
4. 提 PR，附一句「这条技能在哪个真实项目中验证过（文字描述即可，不放图）」。

## 版权与隐私

- 公开条目**不含证据图** —— 那来自第三方参考视频，公开就是转载。
- 证据只在 `SKILL.md` 里用文字描述（如“办公室对话项目 s01/s02 固定机位”），不引用确切文件名。
- `skills/` 不经过 `data/` 忽略规则，会随仓库提交；`pre-commit` 钩子会拦截密钥与 `data/` 路径，不会拦截这里。

语言 / 视觉模型

MiniMax H3 视频

icompify 走远程接口，按次计费；local 走本地 GPU 网关，免费但占用显存，不需要 API Key。

本地视频网关（provider=local）

网关需自行部署并实现 /v1/jobs 接口，见 docs/local-gpu.md。单 worker 串行，出图与出片不能同时跑；不支持尾帧、参考视频，ref2va 只用第 1 张参考图。

小红书视频下载

需要先在对应浏览器登录小红书；Safari 需要给终端完全磁盘访问权限。

图片模型（定妆照 / 场景照，可选）

接口类型填 local 只走本地 GPU；填 auto 优先可用后端，远程不可用/未配置时回退。本地免费，远程按张计费。

本地 GPU 出图（直连或 SSH，可选）

auto 在本机同时存在脚本与 Python 时直连，否则按 SSH 主机走远端；direct 只在本机 spawn，不经过 SSH/scp。短边 768 = 16:9 输出约 1344×768。
